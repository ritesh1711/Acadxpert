# AcadXpert Admission System

This is a web application for managing student admissions.

## Getting Started

1. Clone the repository
2. Install dependencies:
```
cd backend
npm install

cd ../frontend
npm install
```

3. Start the backend server:
```
cd backend
npm start
```

4. Start the frontend development server:
```
cd frontend
npm start
```

5. Access the application at http://localhost:3000

## Login Instructions

- **Student Login**: Use your registered email and password to access the student portal 
- New users can register by clicking on "Sign up here" on the login page
